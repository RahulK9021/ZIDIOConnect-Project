# Job Portal System
A full-stack web application that connects job seekers with recruiters. This platform allows recruiters to post jobs and manage applicants, while candidates can search and apply for jobs.
##  Features
###  Recruiter
- Post and manage job listings
- View and track applicants
- Resume viewing functionality
- Manage applications through dashboard
###  Candidate
- Browse available job opportunities
- Apply for jobs
- Track application status
##  Architecture
- MVC (Model-View-Controller) architecture
- DAO design pattern for database operations
- Layered structure for better maintainability
##  Tech Stack
- **Backend:** Java, Servlets, JSP, JDBC  
- **Frontend:** HTML, CSS, JavaScript, Bootstrap  
- **Database:** MySQL  
- **Tools:** Git, GitHub  
##  Security
- Session-based authentication
- Role-based access control (Recruiter / Candidate)
- SQL injection prevention using PreparedStatements
